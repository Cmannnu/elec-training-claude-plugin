# UK Electrical Qualifications — Claude Plugin

A small educational Claude plugin by **Elec Training** that helps users understand UK electrician qualification routes and common City & Guilds course codes.

## What it does

The plugin contains three skills:

1. **Qualification Route** — explains the usual adult journey from Level 2 through Level 3, 18th Edition, NVQ, AM2 and ECS Gold Card.
2. **Course Code Decoder** — explains common course and assessment codes in plain English.
3. **Which Course Next?** — asks about a user's existing qualifications/experience and identifies the likely next stage.

## Example prompts

- "I'm 34 and have no electrical experience. What qualifications do I need to become an electrician in the UK?"
- "I've finished Level 2 and my 18th Edition. What should I do next?"
- "What is the difference between 2365-02, 2366-03, 2357 and AM2?"
- "Do I need Part P to become a qualified electrician?"

## Scope and accuracy

This plugin provides general educational guidance, not legal, regulatory, employment or certification guarantees. Electrical qualification frameworks change over time. Course codes and registration availability should be checked against the latest awarding-body and industry requirements before a learner makes an enrolment decision.

## Maintenance note

The Level 3 NVQ route is in a period of transition in late 2026. Review references to 2357 before accepting future updates so the plugin does not keep an obsolete qualification code after new registrations change.
